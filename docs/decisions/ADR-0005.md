# ADR-0005: PWA before native mobile

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

Investigation belongs on the web; mobile value is primarily alert review and triage (plan §19, Decision 5).


## Decision

Build the web application as a responsive PWA first. A native mobile companion (alert inbox, saved summaries, briefings) is a later product, not a duplicate globe.


## Consequences

Mobile layouts prioritize the selected event and evidence drawer over ambient globe decoration (§9.4).
