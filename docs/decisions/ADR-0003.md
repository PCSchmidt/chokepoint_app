# ADR-0003: Cesium remains the visual substrate

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

The globe creates strong visual continuity and makes global chokepoints intuitive, but 3D must not become decoration alone (plan §19, Decision 3).


## Decision

Reuse a CesiumJS globe in Phase 3, restricted to bounded freight-specific layers. Analytical value must remain visible in the timeline, metric, and evidence surfaces.


## Consequences

Cesium is not installed until Phase 3 begins; the application must stay buildable and testable without it (keyless-first §19 Decision 4). A keyless-compatible fallback map stack is required (§4.1).
