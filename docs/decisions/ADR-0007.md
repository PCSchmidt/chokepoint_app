# ADR-0007: Placeholder geofence geometry is blocked from computation

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

The three MVP chokepoints (§2.1) need geofence polygons that have not yet been reviewed. Inventing precise-looking coordinates would present unreviewed data as if it were authoritative (plan §5.4, §20 step 4).


## Decision

MVP chokepoint profiles ship with coarse placeholder bounding boxes flagged `geometryStatus: "placeholder"`. `assertUsableGeofence()` throws when any consumer attempts membership computation against placeholder geometry. Real coordinates require review, a review owner, and a versioned geometry commit.


## Consequences

Entry/exit, vessel-count, and dwell metrics are blocked until reviewed geometry lands (planned in the geofence registry work); this is recorded as a known open item in STATUS.md.
