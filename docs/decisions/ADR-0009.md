# ADR-0009: MIT license for code, separate from data licensing

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md §15

## Context

The plan requires code license and data licenses to remain separate. The
inspiration project (gods-eye-view) is MIT for code with explicit carve-outs
for non-permissive third-party data, which demonstrates the pattern works.

## Decision

Chokepoint's source code is licensed under the MIT License (see `LICENSE`,
copyright Chris Schmidt / PCSchmidt). The MIT grant covers code only.

## Consequences

- Every third-party data source keeps its own license and terms, documented in
  `DATA_SOURCES.md` per the §6.1 admission gate; no data license is implied by
  the code license.
- Bundled or stored provider data requires a per-source carve-out decision;
  fixtures are safe (synthetic, CC0-1.0 declared in their provenance).
- Before any public demo launch, the attribution surface must remain visible
  in-product (§15), not only in the repository.
