# ADR-0002: Evidence before voice

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

A voice demo would optimize for spectacle before correctness. The agent must have a trustworthy deterministic contract to call (plan §19, Decision 2).


## Decision

Build deterministic metrics and evidence bundles before adding voice (§8, §17 Phase 4). No LLM or voice component may be introduced until the deterministic data tools and evaluator gates are stable and tested.


## Consequences

Voice and text-agent work is deferred to Phase 4. `src/agent/` remains a stubbed module boundary.
