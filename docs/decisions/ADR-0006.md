# ADR-0006: Fixture-first ingestion with hard SIMULATED labeling

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

Simulated data that can be confused with live observations would undermine the product's core trust boundary (plan §3.1: SIMULATED is never mixed into observed totals).


## Decision

All ingestion is developed against checked-in fixtures before any live provider exists. The fixture loader (`src/data/fixtureLoader.ts`) hard-fails any manifest whose `truthState` is not exactly `SIMULATED`, whose `simulated` flag is not true, or whose provider id does not start with `simulated`. Every fixture description states that the data is synthetic and not real AIS data.


## Consequences

Simulated and observed data can never be silently merged by construction; the loader, not caller discipline, is the enforcement point.
