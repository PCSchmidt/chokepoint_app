# ADR-0014: Defer rail as a live layer; permit FRA Grade Crossing Inventory as static context only

**Status:** Accepted
**Date:** 2026-09-10
**Source:** CHOKEPOINT-PLAN.md §6, §6.1; research/multimodal-source-research.md

## Context

The design note names "FRA rail crossing data as a second land signal **if a
usable public source exists**". Research on 2026-09-10 verified what the
FRA/BTS open data portal publishes:

- The **Grade Crossing Inventory System (Form 71)** is openly available
  ("Crossing Inventory Data (Form 71) - Current", dataset `m2f8-22s6`,
  updated 2026-09-10; historical variant also published). It is a STATIC
  registry of crossing characteristics (location, characteristics, counts).
- **No live blockage, occupancy, or delay feed is published** by FRA. Live
  rail delay data in the US is held privately by the railroads. The §2.2
  "rail crossing data" signal the note hoped for does not exist publicly.

## Decision

1. **Defer rail as a live layer.** No FRA live adapter will be built, because
   no live source exists to adapt. This is the honest gate outcome, recorded
   rather than skipped.
2. **Permit the Form 71 inventory as future STATIC context only** (e.g.
   rendering crossing locations along the simulated I-corridor truck
   routes). Static context must be labeled as such and must never be
   presented as a movement signal, a delay metric, or evidence of rail
   activity or inactivity.
3. **No rail metrics, agent intents, or fixtures are built in this phase.**
   The rail capability slot stays `deferred` in the source registry.

## Consequences

- The land layer ships with two signals: CBP wait times (OBSERVED, ADR-0013)
  and simulated truck density (SIMULATED by design).
- If a permitted live rail signal emerges later (an authority opening data,
  or a licensed vendor within demo economics), it enters through a fresh
  §6.1 gate pass and a new ADR — the same bar as every other source.
- The rail mode remains visible in `TransportMode` and config vocabulary
  (existing since Phase 0) with no data behind it — the UI must not present
  a rail layer until this decision is revisited.
