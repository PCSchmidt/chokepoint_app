# ADR-0008: Working name "Chokepoint"

**Status:** Accepted (working name)  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md §20 step 1

## Context

The plan requires a product-name decision and a domain/trademark availability
check before launch-facing work. The project needs a stable name for code,
docs, and configuration now.

## Decision

Use **Chokepoint** as the working name. It names the product's core subject
(the global maritime chokepoints) without claiming authority, and it is short
enough for UI labels and a domain. This is a working-name decision, not a
final trademark clearance.

## Consequences

- Package name, config ids, and docs use `chokepoint` consistently.
- Domain/trademark availability remains unchecked; a final name review is
  required before any public launch (Phase 6).
- The name deliberately avoids surveillance-flavored vocabulary (§9.3), which
  matches the freight-operations visual direction.
