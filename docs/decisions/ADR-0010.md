# ADR-0010: Admit AISStream.io as the first live AIS provider (risk-accepted)

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md §6, §6.1, §15; research/ais-provider-research.md

## Context

The §6.1 admission gate requires every source to document its terms before
production configuration. Research (2026-09-09) verified that AISStream.io is
free, documents its operational limits and honest failure behavior, provides
the `ShipStaticData` classification field Chokepoint needs — and publishes
**no data-use terms of any kind** (terms pages 404; only a personal-data
privacy policy). Alternatives are unfit for a software-only portfolio demo:
ais.fm is defunct, AISHub requires operating receiver hardware, and the paid
options (Datalastic, MarineTraffic/Kpler) conflict with demo economics
(Datalastic additionally forbids derivative databases).

## Decision

Admit AISStream.io as the first live AIS provider, as an explicit,
documented **risk acceptance** by the project owner (portfolio demo,
non-commercial):

1. The absence of published data-use terms is recorded as the terms decision,
   not papered over. The §6.1 "terms and commercial status" item is satisfied
   by documenting the verified absence.
2. Raw AIS messages are never committed to the repository and never
   redistributed; retention is a short-TTL in-memory buffer (<= 72 h).
3. Only derived aggregates and normalized observations may be persisted.
4. The API key stays server-side (provider explicitly bans browser
   connections; matches §14.1).
5. Courtesy attribution ("Live AIS via AISStream.io") with a coverage caveat
   appears in the visible attribution control (§15).
6. The provider remains swappable via the Phase 1 source-adapter interface;
   the removal plan is: fall back to fixture/historical replay (NOAA
   MarineCadastre / Danish DMA), paid provider as last resort.

## Consequences

- Singapore/Malacca and Suez are **live-only**: AISStream has no history, and
  free historical AIS exists only for US (NOAA) and Danish (DMA) waters. The
  owner accepted this; the three MVP chokepoints remain as planned (§2.1).
  Baseline comparisons at Suez/Malacca must start from live accumulation.
- Data loss is normal operation, not exceptional: the health-state machine
  must treat stream gaps as expected and metrics must carry freshness caveats.
- From September 2026 AISStream throttles uncompressed connections; the future
  adapter must enable permessage-deflate from day one.
- Account creation (GitHub sign-in) and empirical per-chokepoint coverage
  measurement are required Phase 2 actions to close the coverage item.
