# ADR-0001: Maritime-first MVP

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

Chokepoint must produce deep, evidence-backed analysis quickly. Launching sea, air, and land modes simultaneously would create inconsistent coverage and unclear metric semantics (plan §19, Decision 1).


## Decision

Begin with sea freight and exactly three chokepoints (Los Angeles / Long Beach, Singapore / Malacca approach, Suez Canal approaches — §2.1). Air and land modes are added only after the maritime workflow is demonstrably useful (§20 step 12).


## Consequences

All Phase 0–2 schemas (`mode`, `entityType`) already name air/land/rail values, so expansion is additive; but metric semantics, fixtures, and review effort stay concentrated until the maritime pipeline is validated.
