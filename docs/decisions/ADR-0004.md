# ADR-0004: Keyless-first validation

**Status:** Accepted  
**Date:** 2026-09-09  
**Source:** CHOKEPOINT-PLAN.md (§ references in body)

## Context

Premature provider lock-in and non-reproducible CI are risks. Controlling cost and avoiding credential-dependent builds are priorities (plan §19, Decision 4).


## Decision

The project runs without optional credentials using synthetic replay fixtures and small checked-in SIMULATED fixtures (§6.2). CI and all Phase 0/1 tests require zero secrets (§16.1). A missing provider key must not make the application appear broken.


## Consequences

Every live source must pass the §6.1 admission gate before production configuration; fixture mode remains a first-class, always-available runtime mode.
